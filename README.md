# MiniFactory

구리와 석탄 광맥에서 시작해 채굴기, 컨베이어, 제련기를 연결하는 2D 공장 자동화 게임입니다. 직접 만든 제품을 판매해 **누적 매출 500,000크레딧**을 달성하면 엔딩이 열립니다. 건설과 연구에 돈을 써도 누적 매출은 유지됩니다.

## 소스 실행

Windows에서 Python 3.14를 설치한 뒤, 이 README와 `main.py`가 있는 폴더에서 PowerShell을 엽니다.

```powershell
py -3.14 -m pip install -r requirements.txt
py -3.14 main.py
```

게임은 pygame-ce를 사용하며, 시작 화면에서 한국어와 영어를 선택할 수 있습니다.

## 첫 생산 라인 만들기

1. **채굴** — 하단에서 채굴기를 선택하고 구리 광맥에 설치합니다. 설치 전에 `R`을 눌러 출력 화살표를 빈칸으로 돌립니다.
2. **보관과 첫 출하** — 화살표 바로 앞에 창고를 놓거나 컨베이어로 연결합니다. 창고에 구리 광석 10개가 쌓이면 오른쪽 출하 버튼을 눌러 450크레딧을 받습니다. 석탄 10개로 시작해도 됩니다. 계약 보상은 누적 매출에서 제외됩니다.
3. **제련** — 구리 광석을 제련기의 뒤나 옆으로 보내고 출력 쪽에 창고를 둡니다. 제련기를 선택하고 `Q`에서 **구리 제련**을 적용합니다. 석탄도 공급할 수 있다면 **석탄 구리 제련**을 고르세요. 구리 광석 1개와 석탄 1개로 같은 주괴를 두 배 빠르게 만듭니다.
4. **철광석 해금** — 구리 주괴가 든 창고를 선택하고 주괴를 `T`로 꺼냅니다. 주괴 3개와 200크레딧을 모아 연구 화면(`Y`)에서 철광석 채굴을 해금합니다. 이후 제련기의 `Q` 목록에서 **철 제련**(철광석 1개 → 철판 1장, 기본 1.2초) 또는 **석탄 철 제련**(철광석 1개 + 석탄 1개 → 철판 1장, 기본 0.6초)을 선택합니다.
5. **판매 자동화** — 처음에는 창고에서 꺼낸 물품을 판매소(`M`)에서 팝니다. 고급 가공과 공장 자동화 연구를 마치면 창고 → 배출기 → 자동 판매기를 연결하세요. 배출기에서 품목을 지정하면 창고에서 꺼내 판매하는 과정이 자동화됩니다.

맵 아래 재고 목록에서 창고 수량과 소지 수량을 함께 확인할 수 있습니다. 창고를 클릭하면 해당 창고의 재고가 표시됩니다. 제작 재료가 헷갈릴 때는 **도움말(`Tab`) → 재료 제작법**에서 완성품을 선택하세요.

## 설비 업그레이드

설비를 선택하고 `U`를 누르면 크레딧과 소지 재료를 써서 한 단계 올립니다. 모든 설비는 목표 레벨만큼 기계 부품이 필요합니다(2레벨 2개, 3레벨 3개, 4레벨 4개, 5레벨 5개). 업그레이드 버튼 아래에서 크레딧과 재료별 소지량/필요량을 확인하세요. 부족한 항목에는 추가로 필요한 수량이 빨간색으로 표시됩니다. 첫 부품은 철광석 채굴 연구 후 조립기에 철판 2장을 넣어 1개씩 만들 수 있습니다. 창고에 있는 부품은 먼저 꺼내세요.

## 주요 조작

| 조작 | 기능 |
| --- | --- |
| 하단 설비 클릭 → 맵 왼쪽 클릭 | 설비 선택 및 설치 |
| 컨베이어 선택 후 왼쪽 드래그 | 경로를 따라 벨트 설치 |
| 오른쪽 클릭 | 설비 철거 |
| `R` / `Shift+R` | 설치 방향 / 선택한 설비 방향 회전 |
| 마우스 가운데 버튼 드래그 / 휠 | 카메라 이동 / 확대·축소 |
| `Q` / `U` | 선택한 설비의 제작법 변경 / 업그레이드 |
| `F` / `T` | 재료 넣기 / 창고에서 꺼내기 |
| `M` / `Y` / `Tab` | 판매소 / 연구 / 도움말 |
| `Space` / `F11` | 일시정지 / 전체 화면 전환 |
| `F5` / `F9` | 저장 / 불러오기 |

Windows 저장 위치는 `%LOCALAPPDATA%\MiniFactory\factory.json`입니다. 언어 설정은 같은 폴더의 `settings.json`에 기록됩니다.

## 소스 구성

| 파일 | 역할 |
| --- | --- |
| `main.py` | 게임 시작과 입력 처리 |
| `simulation.py` | 건설, 생산, 운송, 창고 재고 및 판매 처리 |
| `game_data.py` | 설비 가격, 제작법, 연구 비용, 엔딩 목표(`SALES_TARGET`) |
| `interface.py`, `graphics.py` | 게임 화면과 설비·재료 그래픽 |
| `tutorial.py`, `example_layouts.py` | 단계별 안내 및 예제 공장 |
| `translations.py` | 한국어·영어 표시 문구 |
| `save_game.py` | JSON 저장과 불러오기 |
| `assets/`, `tests/` | 이미지·글꼴 및 자동 테스트 |

## 테스트와 Windows 실행파일 제작

자동 테스트는 소스 폴더에서 실행합니다.

```powershell
py -3.14 -m unittest discover -s tests -v
```

Windows에서 아래 배치 파일을 실행하면 가상환경을 만들고 PyInstaller로 이미지와 글꼴을 포함한 단일 실행파일 `dist/MiniFactory.exe`를 생성합니다.

```powershell
.\build_windows.bat
```
