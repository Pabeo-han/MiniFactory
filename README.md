# MiniFactory

60×40칸의 공장에 채굴기와 컨베이어를 놓고, 광석이 가공 설비를 거쳐 창고까지 흐르도록 생산 라인을 설계합니다. 광석이 제련기 앞에 쌓이면 옆에서 석탄을 공급해 가공 시간을 줄일 수 있습니다. 완성된 기계 부품은 팔아서 다음 설비를 짓거나 기존 설비를 강화하는 데 씁니다.

**목표는 누적 매출 50만 크레딧입니다.** 직접 판매하거나 자동 판매기로 번 금액이 합산됩니다. 설비를 짓고 연구에 투자해도 매출 기록은 유지되며, 엔딩을 본 뒤에도 같은 공장을 운영할 수 있습니다.

## Windows에서 소스로 실행하기

개발 환경은 Windows, Python 3.14.7, pygame-ce 2.5.8입니다. 저장에는 JSON을 사용합니다.

1. 저장소를 다운로드하고 압축을 풉니다.
2. Python 3.14가 설치된 PC에서 `main.py`가 있는 폴더를 열고 PowerShell에서 아래 두 줄을 실행합니다.


시작 화면에서 한국어 또는 영어를 선택합니다. **새 공장 시작**을 누르면 1,000크레딧으로 시작합니다. 벨트가 연결된 모습을 먼저 보려면 **기본 생산 예제**를 선택하세요.

## 단일 실행파일 만들기

같은 폴더에서 다음 명령을 실행하거나 `build_windows.bat`를 더블클릭합니다. 처음 빌드할 때는 필요한 패키지를 다운로드할 인터넷 연결이 필요합니다.

```powershell
.\build_windows.bat
```

배치 파일은 가상환경을 준비하고 PyInstaller로 게임 코드, 이미지, 글꼴을 묶습니다. 빌드가 끝나면 **`dist\MiniFactory.exe`**가 생성됩니다. 이 파일은 Python이 설치되지 않은 Windows PC에도 전달할 수 있습니다.

## 첫 공장에서 판매 자동화까지

| 목표 | 해볼 일 |
| --- | --- |
| 첫 출하 | 구리 또는 석탄 광맥 위에 채굴기를 놓습니다. 출력 화살표 앞에 창고를 두거나 벨트로 연결합니다. 창고에 한 종류가 10개 모이면 출하해 450크레딧을 받습니다. 계약 보상은 운영 자금에 더해집니다. |
| 철광석 연구 | 제련기에서 구리 광석을 주괴로 만듭니다. 창고에서 구리 주괴 3개를 꺼낸 뒤 `Y`를 눌러 200크레딧으로 철광석 채굴을 연구합니다. |
| 철판과 부품 생산 | 철광석 1개를 제련하면 철판 1장이 됩니다. 철 연구 후 `Q`에서 **석탄 철 제련**을 선택하고 석탄 1개를 함께 공급하면 기본 가공 시간이 1.2초에서 0.6초로 줄어듭니다. 조립기에서는 철판 2장으로 기계 부품 1개를 만듭니다. |
| 판매와 강화 | 창고에서 꺼낸 부품은 판매소에서 개당 95크레딧에 팔 수 있습니다. 제련기를 2레벨로 강화하려면 기계 부품 2개, 철판 2장, 300크레딧을 준비합니다. |
| 자동 판매 | 고급 가공과 공장 자동화를 연구합니다. 창고 옆 배출기에서 품목을 선택하고 출력 쪽을 자동 판매기에 연결하면 직접 물건을 꺼내는 과정이 자동화됩니다. |

**생산이 멈췄을 때**는 설비를 클릭해 제작법과 출력 방향을 확인하세요. 제련기는 뒤와 양옆으로 재료를 받습니다. **강화가 막혔을 때**는 업그레이드 버튼 아래의 빨간 부족 수량을 확인하세요. 창고에 재료가 있다면 먼저 소지품으로 꺼냅니다.

## 조작과 저장

| 조작 | 기능 |
| --- | --- |
| 하단에서 설비 선택 후 왼쪽 클릭 / 오른쪽 클릭 | 설치 / 철거 |
| 컨베이어 선택 후 왼쪽 드래그 | 경로를 따라 벨트 설치 |
| `R` / `Shift+R` | 설치 미리보기 회전 / 선택한 설비 회전 |
| 마우스 가운데 버튼 드래그 / 휠 | 카메라 이동 / 확대·축소 |
| `Q` / `U` | 제작법 선택 / 설비 업그레이드 |
| `F` / `T` | 재료 넣기 / 창고에서 꺼내기 |
| `M` / `Y` / `Tab` | 판매소 / 연구 / 도움말과 재료 제작법 |
| `Space` / `F11` | 일시정지 / 전체 화면 전환 |
| `F5` / `F9` | 저장 / 불러오기 |

공장은 `%LOCALAPPDATA%\MiniFactory\factory.json`에 저장됩니다. 언어 설정은 같은 폴더의 `settings.json`에 기록됩니다.

## Python 구현과 테스트

| 파일 | 담당하는 일 |
| --- | --- |
| `main.py` | 게임 실행, 키보드·마우스 입력 처리 |
| `game_data.py` | 제작법, 가격, 연구 조건, 엔딩 목표 정의 |
| `simulation.py` | 타일 좌표별 설비 관리, 0.1초 단위 생산·운송·재고 계산 |
| `interface.py`, `graphics.py` | 조작 화면, 공장 지도, 설비와 아이템 그리기 |
| `save_game.py` | JSON 저장과 복원 |
| `tutorial.py`, `example_layouts.py`, `translations.py` | 진행 안내, 예제 공장, 한영 문구 |
| `assets/`, `tests/` | 이미지·글꼴, 자동 테스트 |

`main.py`가 있는 폴더에서 다음 명령으로 테스트를 실행합니다. 제작법 해금, 재료 소모와 생산, 벨트 운송, 업그레이드 비용, 저장 후 복원 등을 검사합니다.

```powershell
py -3.14 -m unittest discover -s tests -v
```
